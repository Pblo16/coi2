# COI2 - Financial Management System

COI2 is a comprehensive financial management system designed to handle accounting, policy management, and financial reporting for organizations. The system provides tools for tracking transactions, generating financial reports, and managing billing processes.

## Overview

This application is built using a modern tech stack including:
- Frontend: React with TypeScript, using Inertia.js for server-side rendering
- Backend: PHP (Laravel framework)
- UI Components: Custom UI components with shadcn/ui styling

## Modules

### Dashboard
The central hub providing an overview of the system's key metrics and quick access to all modules.

### Policies Management
Manage insurance or financial policies with features for:
- Creating and editing policies
- Managing sub-policies
- Assigning accounts and permissions

### Billings
Process and manage billing operations:
- Generate invoices
- Export billing data
- Track payment status

### Reports
Generate comprehensive financial reports:

#### General Ledger (Balanza General)
- View account balances across all policies
- Filter by date range and policy
- Export reports in spreadsheet format

#### Account Books (Libro Mayor)
- Detailed transaction history for specific accounts
- Filter by date range and sub-policy
- View detailed transaction entries

### Accounting
Core accounting functionality:
- Chart of accounts management
- Journal entries
- Transaction recording and tracking
